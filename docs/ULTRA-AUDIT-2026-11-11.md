# Ultra audit, 2026-11-11

This pass re-checked the open items in
`docs/GOVERNANCE-AUDIT-2026-08-03.md` against the repository as it is now,
then closed the ones that can be closed without inventing patterns.

## Measured

- 890 published entries across 29 families. `docs/PROGRESS.md` reports
  completion at 100 percent of the sourced target.
- `docs/AUTHORING-QUEUE.json` holds 3 deferred rows and nothing else.
  `docs/SCOPE-TARGET.json` records a gap of 3 against an older round number
  of 893. Those rows stay deferred for the reasons written on each row.
- 765 `related` and `incompatible_with` values did not name a published
  slug. Twelve slugs are shared by two families, so a bare slug was
  ambiguous for those names.
- 4 internal markdown links pointed at files that are not there.
  `docs/AUTHORING-PLAN.md` does not exist, and three same-folder links in
  `patterns/04-principles-and-laws/predictable.md` pointed at entries that
  live in other families.
- `react.md` carried the slug `react-prompting`.
- Eight release entries had `verified` set to the boolean true instead of
  a date.
- `GOVERNANCE.md`, `MAINTAINERS.md`, `docs/CITATION-POLICY.md`, and
  `schema/pattern.schema.json` were absent.
- `dist/catalogue-status.json` and `dist/catalogue-status.csv` were deleted
  in the working tree and not committed. The generator restores them.
- `.github/CONTRIBUTING.md` and `ATTRIBUTION.md` still named OpenRoots Agent
  License 1.0. The license file is 2.3.
- Several items the August audit listed as missing were already present.
  `docs/BY-PROBLEM.md`, `docs/BY-LANGUAGE.md`, validator tests, issue
  templates, `SECURITY.md`, `CODEOWNERS`, and Dependabot.

## Closed in this change

- Stable id, kind, last reviewed, and next review due on every entry.
- `related` and `incompatible_with` now resolve to published entries.
  Names that are not entries moved to `related_concepts` and
  `incompatible_concepts`. Aliases are not followed automatically, because
  short aliases such as windowing, pipeline, and snapshot point at the
  wrong pattern. Renames that do mean one entry are listed in
  `tools/catalogue_model.py`.
- `tools/check-links.py` gates internal links and that identity. It is on
  `make check` and in CI.
- `dist/entries.json`, generated by `tools/gen-entry-index.py`, is the
  machine-readable export. Its applicability field is an excerpt of
  dimension 4, not a newly written decision block.
- `schema/pattern.schema.json` documents the frontmatter. The enforcing
  tool is `tools/check-links.py`, which uses the Python standard library.
- `GOVERNANCE.md`, `MAINTAINERS.md`, and `docs/CITATION-POLICY.md`.
- The ReAct file is `patterns/17-ai-agentic/react-prompting.md`.
- The predictable-entry links and the README authoring links point at
  files that exist.
- The 1.0 license strings now say 2.3.

## Left open on purpose

- The three deferred queue rows. Authoring them would invent a taxonomy,
  collapse stream windowing into the UI virtual list, or duplicate
  memory compaction without a human confirmation.
- The 24 patterns in `docs/CATALOG-COMPARISON.md` that need a new family.
  Smart contracts, game development, and classical ML are the groups.
  That is a scope decision the comparison file already refuses to make
  silently.
- The UX widget catalogue and the GOV.UK content-design catalogue. Both
  were surveyed and recorded as a different genre, not as missing entries.
- Citation relevance. A live URL is still not proof the page supports the
  sentence. The policy names that limit. No classifier was added.
- A documentation site. The repository is still markdown plus the JSON
  export.
- A four-line decision summary written onto each of the 890 entries.
  The export carries an excerpt instead.
- The three-language code minimum. Changing it would reopen every
  published entry and needs its own decision.
- Workflow states such as draft, in review, and superseded. Still not
  modelled.
- A second domain reviewer. Named in `MAINTAINERS.md`.
- CodeQL and an OpenSSF Scorecard workflow. Dependabot is already
  configured for GitHub Actions.
